## QuickTools 目录约定

- 这里只放快速工具运行时能力和状态实现，例如能力判断、执行器、媒体状态桥接和控制中心状态。
- Compose 页面级配置不要放这里；配置页留在 `ui/screen/quicktools/`。
- 这里对外暴露稳定的小接口，不让 UI 层直接拼 Shell 命令或直接依赖系统细节。
- 运行时控制中心统一使用固定竖屏样式弹窗，不再按横竖屏分两套布局。
- 运行时控制中心使用固定 `4` 列、可滚动 `6` 行视口的网格布局，弹窗宽高固定为 `240dp x 300dp`。
- 运行时控制中心的展示顺序严格跟随用户在配置页里的排序结果，不对媒体、亮度、音量做额外置顶或分区重排。
- 工具占格由 `QuickToolType` 派生并集中维护：媒体卡 `4x2`、滑条 `4x1`、普通按钮 `1x1`；不要把这类布局规则散落到多个 Compose 分支里。
