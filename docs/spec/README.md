## 索引维护约束

- 新增 SPEC 必须覆盖这些语义章节：状态、复杂度、问题与目标、当前行为与证据、范围、非目标、产品／交互决策、技术方案、数据与兼容性、验收标准、风险与待确认、关联代码；大型 SPEC 可使用语义等价的分节，并按需要扩展内容。
- 代码证据链接从本目录出发使用 `../../app/...` 相对路径；实现路径变化时应同步更新链接。
- 需求完成前保持“草案”或“待实施”状态，并在实现和验证后同步更新根 `ROADMAP.md`。
